Os meses são calculados automaticamente a partir dos lançamentos diários (soma para volume, média para os demais indicadores). Energia ARM/TERM usa o valor manual se existir; senão, calcula automaticamente a partir do kWh sincronizado da Way2 dividido pela produção do dia.

Lançamento do dia

Metas por indicador

"Sincronizar energia" chama o endpoint seguro /api/sync-energy (função Vercel), que busca o kWh do dia na Way2 e grava no banco — as credenciais da API nunca passam pelo navegador. Isso também roda sozinho todo dia de madrugada.
Clique no ✕ para excluir um dia. Clique em qualquer célula para editar e pressione Enter ou saia do campo para salvar. Colunas de energia mostram o valor manual; se vazio, o dashboard usa o kWh sincronizado ÷ produção automaticamente.
